## Week 1 — AWS Fundamentals

### Day 1: Identity and Access Management (IAM)

**What I learned:**

- IAM manages access to AWS resources.
- Users, groups, and roles help manage identities and access.
- IAM policies define permissions.
- The principle of least privilege helps reduce security risks.

**Security best practices:**

- Enable multi-factor authentication (MFA).
- Avoid using the root account for everyday activities.
- Grant only the permissions required for each task.
- Prefer temporary credentials when possible.
